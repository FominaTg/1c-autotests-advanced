# 1c-autotests-advanced

Домашнее задание к занятию «Расширенный функционал автоматизированного сценарного тестирования» (курс «Программист 1С», Нетология). Инструмент — Vanessa Automation single 1.2.043.1.

Сценарии предыдущего занятия (репозиторий [1c-autotests](https://github.com/FominaTg/1c-autotests)) переделаны в экспортные параметризованные шаги библиотеки и вызываются из одного главного теста.

## Структура

```
Library/                                 — библиотека экспортных сценариев (подключена в Vanessa → «Библиотеки»)
    01_Nomenklatura.feature
    02_Kontragent.feature
    03_Postuplenie.feature
    04_OplataPostavshchiku.feature
    05_PostuplenieBezKontragenta.feature
    06_ZagolovokFormy.feature
Main/
    00_MainTest.feature                  — главный тест, вызывает все экспортные сценарии
screenshots/                             — скриншоты результатов
```

## Задание 1. Экспортные сценарии в библиотеке шагов

Сценарии прошлого занятия переделаны в экспортные. В шапке каждого файла заданы теги:

- `@ExportScenarios` — сценарий становится шагом библиотеки;
- `@ТипШага: Нетология. Свои шаги` — группа, в которой шаг отображается;
- `@Описание` — назначение шага;
- `@ПримерИспользования` — пример вызова.

Папка `Library` добавлена в Vanessa Automation (вкладка «Библиотеки»). После этого в «Известных шагах» появилась группа «Нетология → Свои шаги» с шестью шагами, и их можно вставлять в любой сценарий.

Подготовка данных (создание контрагента) вынесена в отдельный шаг, чтобы не дублировать её в поступлении и оплате.

Ошибочный сценарий прошлого ДЗ (`задание_3.feature` в репозитории 1c-autotests, ожидался неверный заголовок «Товар (создание)») сделан рабочим: ожидаемый заголовок теперь передаётся параметром, и главный тест передаёт верное значение «Номенклатура (создание)».

## Задание 2. Параметризация

Значения, которые раньше были прописаны внутри сценариев, вынесены в параметры. Параметр объявляется в кавычках в строке `Сценарий:`, а внутри шагов используется как `'[ИмяПараметра]'`. При вызове шага на его место подставляется переданное значение.

| Экспортный сценарий | Параметры |
|---|---|
| Я создаю номенклатуру … | НаименованиеНоменклатуры, Папка, Группа, Единица, Вид |
| Я создаю контрагента … | НаименованиеКонтрагента, ГруппаКонтрагента, ИННКонтрагента, КППКонтрагента |
| Я создаю и провожу поступление … | ИмяКонтрагента, ИмяДоговора, ИмяТовара, КоличествоТовара, ЦенаТовара, СуммаТовара |
| Я создаю и провожу оплату поставщику … | ИмяКонтрагента, ИмяДоговора, СуммаОплаты |
| Я проверяю, что поступление … не проводится без контрагента | ИмяТовара, КоличествоТовара, ЦенаТовара |
| Я проверяю, что форма новой номенклатуры открывается с заголовком … | ОжидаемыйЗаголовок |

Пример — один сценарий создания номенклатуры вызывается дважды с разными значениями:

```gherkin
И я создаю номенклатуру "Диван" в новой папке "Гостиная" с номенклатурной группой "Мебель" единицей "шт" и видом "Товар"
И я создаю номенклатуру "Шкаф" в новой папке "Спальня" с номенклатурной группой "Мебель" единицей "шт" и видом "Товар"
```

Параметры в экспортном сценарии:

![Параметры в экспортном сценарии](screenshots/l2_task2_params.png)

Раскрытый вызов — значения подставлены во вложенные шаги:

![Подстановка значений параметров](screenshots/l2_task2_expanded.png)

**Замечание.** Имя параметра не должно совпадать с именем поля формы или заголовком колонки. Vanessa подставляет значение в любую строку в кавычках, равную имени параметра. В первой версии параметр назывался `"Контрагент"`, и значение подставилось в имя поля `'Контрагент'`, из-за чего шаг не нашёл поле. Параметры переименованы (`ИмяКонтрагента` и т. п.).

## Задание 3. Главный тест

`Main/00_MainTest.feature` — общий сценарий, который по очереди вызывает все экспортные сценарии и передаёт в них параметры:

1. создание номенклатуры «Диван» с проверкой реквизитов;
2. подготовка данных: номенклатура «Шкаф», контрагент ООО «Поставщик»;
3. поступление: «Шкаф», 10 × 1 500,00 = 15 000,00;
4. оплата поставщику на 15 000,00;
5. негативная проверка: поступление без контрагента не проводится;
6. проверка заголовка формы новой номенклатуры.

Результат: выполнено 169 шагов (вместе с вложенными), ошибок нет.

![Результат главного теста](screenshots/l2_task3_main.png)

## Как запустить

1. Запустить информационную базу с параметром `/TESTMANAGER`, открыть `vanessa-automation-single.epf`.
2. Во вкладке «Библиотеки» добавить папку `Library` и сохранить настройки.
3. Перезапустить Vanessa Automation, открыть `Main/00_MainTest.feature` и запустить выполнение.
