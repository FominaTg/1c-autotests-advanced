# 1c-autotests-advanced

ДЗ к занятию «Расширенный функционал автоматизированного сценарного тестирования».

## Файлы

- `Library` — экспортные сценарии (папка добавлена в Vanessa во вкладке «Библиотеки»)
- `Main/00_MainTest.feature` — главный тест
- `screenshots` — скриншоты

## Задание 1

Сценарии из прошлого ДЗ сделала экспортными (теги `@ExportScenarios`, `@ТипШага`, `@Описание`, `@ПримерИспользования`). Создание контрагента вынесла в отдельный шаг. Сценарий с ошибкой исправила: ожидаемый заголовок формы теперь передаётся параметром.

![](screenshots/l2_task1_library.png)
![](screenshots/l2_task1_insert.png)

## Задание 2

Значения вынесла в параметры: в названии сценария `"ИмяПараметра"`, в шагах `'[ИмяПараметра]'`.

![](screenshots/l2_task2_params.png)
![](screenshots/l2_task2_expanded.png)

Сначала назвала параметр `Контрагент`, как поле на форме, и Vanessa подставила значение в имя поля — тест упал. Переименовала параметры.

## Задание 3

Главный тест вызывает все экспортные сценарии с параметрами. Ошибок нет.
